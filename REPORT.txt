SOL_ATTN calls the upstream fused implementation. No provider/native flag,
cuDNN BSA composition, or Omni residual kernel remains. H3's disjoint block64
text/audio metadata is forwarded as exact_block_mask, protecting both Q/KV axes.
The dependency adds that generic API to the upstream kernels.

Final 2x GH200 96GB Ref2VA, official 768p/5s request, BF16, TP1/Ulysses2:
  Dense cuDNN: 10752.560 ms; CV 0.0899%; range 10735.598–10765.670 ms
  Upstream SOL: 6555.892 ms; CV 0.0725%; range 6550.321–6565.456 ms
  Ratio of medians: 1.640137x; latency reduction 39.029%
  Median paired speedup: 1.640572x; all 9 pairs faster.

Each process uses three warmup pairs and nine measured pairs, alternating order.
Each sample is the synchronized maximum wall latency across two ranks for one
full 50-layer DiT forward. CPU offload is equal for capacity; transfers precede
the measured boundary. The run intentionally stops before sampler advancement
and VAE decode. This is not end-to-end video generation latency.
