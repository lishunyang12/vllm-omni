Scope and result
One complete 50-layer DiT forward at the first conditional denoising step.
2x GH200 96GB (SM90), BF16, TP1/Ulysses2, eager; official 768p/5s Ref2VA,
seed0, 50-step schedule, guidance1, flow_shift12/audio_flow_shift3.
CPU offload enabled equally for capacity; DiT weights resident during timing.
Three warmups + nine identical-input replays, synchronized max-rank wall median.
No profiler during latency measurements. Every input hash matches.

Change and reason
The prior profile attributed 7107 ms to the eager SOL residual. Four Triton
pointwise kernels replace eager pointwise stages. Eight original 256-row GEMMs
are grouped per outer launch, preserving the original row shapes and ragged tail,
FP32 matrix arithmetic, PyTorch sum reduction tree, and separate LSE/logaddexp
rounding. Routing, sparse selections, protected sinks, block multiplicity, and
BF16 output are unchanged. No new CLI option or dependency.
The captured single-layer residual trace drops from 8104 to 463 GPU kernels.
In micro-profile-grouped/counts.json the key "fused" denotes this grouped
candidate; it is distinct from the rejected full-forward directory ref2va-fused.

Numerical validation
The complete forward's two outputs (video [74592,96], audio [1242,32], float32)
are byte-for-byte equal to original SOL for both ranks, first/last outputs,
standalone and fresh paired process. Comparison uses contiguous uint8 views,
including signed zeros; maximum absolute error and relative L2 are both zero.
This is equality to original SOL on this workload, NOT equality to Dense or a
claim about all inputs/devices/denoising steps. SOL remains an approximation.
No complete sampling/VAE decoding or SSIM/PSNR/LPIPS measurement was performed.
The intentional H3_FORWARD_BENCHMARK_COMPLETE exception ends each successful
capture before the sampler advances; it is not a benchmark failure.

Rejected/intermediate experiments (retained for audit, not headline results)
ref2va-fused: 9161.605 ms (repeat 9176.373), but changed full-forward output;
video relative L2 1.3344%, audio 8.4499%. Regrouped normalization/chunk2048 rejected.
ref2va-precise: 9848.283 ms; video relative L2 1.1919%, audio 8.2462%.
Preserving normalization alone was insufficient with 2048-row GEMMs.
A shadow diagnostic isolated single-BF16-element changes in six layers when
changing GEMM row shape; the original 256-row shape matched all 50 layers.
ref2va-final/final-repeat: correct unbatched 256-row fusion, 11473.803/10732.645 ms,
CV 4.61/2.52%; paired result also retained. Superseded by grouped implementation.
GC probing did not establish GC as the cause of latency variability; no production
GC policy change. No claim of an established power/contention cause.

Remaining limits
SM100 cuDNN BSA hangs before the residual path; this patch does not fix that issue.
SM103 allocation did not start and was canceled; no result. This is not evidence
of H100/H200/B200/SM103 speedup, full-generation latency, or decoded output quality.
The user's separate SM120 table in the PR is not independently reproduced here.
