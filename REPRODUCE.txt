intentional stop before sampler advancement/VAE decode. No SSIM/PSNR/LPIPS
or end-to-end generation quality claim is made.

Bootstrap installs the exact sources and dependency constraints and downloads
Ref2VA only. Runtime constraints preserve the image's PyTorch/vLLM/CUDA stack.
This bootstrap assembles the validated environment; provisioning itself was
not rerun from an empty checkpoint cache. Full installed environments and
actual model-run protocols are retained in the evidence directories.

The run script starts a fresh process for each invocation, loads the same
weights once, and alternates Dense/SOL order. Three warmup pairs precede nine
measured pairs. Each sample is a synchronized full DiT forward; the reported
latency is the median of the maximum wall time across ranks. Dense uses
CuDNNAttentionImpl as the dense guard on the same attention objects; SOL uses
the unmodified production sparse path. All 50 DiT blocks are checked. Model
CPU offload is enabled equally on GH200 for capacity; weights are resident
inside the measured forward. First/last output tensors and input hashes are
saved outside timing. Existing result directories are rejected.

The harness patches only the measurement boundary and switches the two
attention paths outside timed calls. Production serving needs only:
  --diffusion-attention-backend SOL_ATTN
No provider/native flag is accepted.

The single-GPU Omni suite plus two-GPU Ulysses cases were executed on GH200;
SP4 was not run. The pinned upstream suite was also executed on GB200. This
does not establish full H3 forward latency on GB200, SM103 or SM120.

The upstream PR follows newer sol-engine history separately from the pinned
backport. Its current full sparse-backend suite was tested on GH200/GB200;
see manifest.json for distinct source commits and the logs for skipped cases.

All public logs redact hostnames, IPs, GPU UUIDs and home paths. Private tensor
captures and model weights are not included. compare_outputs.py can derive
forward-tensor error and repeatability from locally saved captures; those
metrics are not decoded-video quality measurements.
