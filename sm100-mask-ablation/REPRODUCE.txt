4. Full first-conditional single-forward comparison
  H3_DESIGN_VARIANT=candidate-fp32 \
  H3_CANDIDATE_PATCH_SHA256=$(sha256sum /work/scripts/patches/pool-fp32.patch | cut -d' ' -f1) \
  H3_GPU_COUNT=2 H3_CPU_OFFLOAD=0 H3_RUN_ID=fp32-450 \
  H3_GPU_FREQ_REQUEST_MHZ=450 bash /work/scripts/run_fp32_forward.sh /work
This is the executed timing harness:3warmup+9rotating/reversed rounds, Dense /
#593+shared fix / #594+shared fix,50layers,TP1/Ulysses2,BF16,cacheoff. It checks
first/last bytes, finiteness and input immutability, then stops before sampler
advancement/VAE decode. It produces no video.
H3_GPU_FREQ_REQUEST_MHZ records intent only; it does NOT set clocks. The tested
cluster control wrapper locks only allocated GPUs, records telemetry and
restores clocks in an EXIT trap. From the host inside your allocation:
  H3_DESIGN_VARIANT=candidate-fp32 H3_CANDIDATE_PATCH_SHA256=PATCH_SHA \
    bash WORK/scripts/control_fp32_forward.sh WORK CONTAINER 2 fp32-450 \
    ALLOCATED_PHYSICAL_GPU_INDICES 450 WORK:/work 0 12
For another scheduler/container runtime, reproduce those ownership checks,

limits. The published full-forward median is max synchronized wall time across
