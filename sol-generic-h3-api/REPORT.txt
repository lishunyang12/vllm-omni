Scope
- Only MiniMax-H3 receives production model-adapter changes.
- Public SOL options: tau, tau_profile, dense_blocks, min_tokens, sink_conditioning.
- Removed options fail validation: thresh_type, kv_splits, dense_steps, dense_layers,
  sink_mode, sink_tokens, sink_start, prefix_sink. Use shared attention schedules
  for denoising intervals. No native/provider or precision flags are added.
- Generic ConditioningBlockMask replaces TextAudioBlockMask. Models own the
  protected token selection and can build the block vector once from a valid-token
  Boolean mask. Protection is separate from causal/pairwise visibility.
- H3 defaults to exact Q-row and KV-column protection for text/audio blocks,
  including generated audio. This is model policy, not a universal requirement.
  sink_conditioning=off explicitly disables it. Required/stale metadata fails
  while protection is enabled; validation is not a quality certificate.
- Generic unconditioned self-attention needs no fabricated conditioning metadata.
  BF16/head128/B1/equal QKV lengths and heads/noncausal/local or pure Ulysses
  restrictions remain. No compatibility claim for other model architectures.

Reproduction
Use reproduce.sh in the fixed image with a writable SOL_REPRO_WORK directory
and two assigned GPUs. It fetches the exact Omni/Sana commits, preserves the
fixed image's core runtime constraints, installs the tested package versions,
and runs both test commands, saving logs/XML/exit status. No model weights are
needed. The script consolidates the executed prepare/test commands; its fetch
wrapper was syntax checked, not rerun in a second clean container.
Commands are literal in reproduce.sh. Keep scheduler-assigned GPU visibility.
The CPU and CUDA regression source matches the commit above; only documentation
was edited after the final test run.
